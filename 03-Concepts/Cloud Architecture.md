## Core Mechanics
Structural design of a cloud computing environment — how servers, storage, databases, networking, and software are integrated to deliver services on demand.
**Core layers:**
- **Front-end platform** — client side (browsers, apps, UIs).
- **Back-end platform** — provider side (virtual servers, storage, security, ops management).
**Delivery models:**
- **IaaS** — raw infrastructure (VMs, storage, networking). E.g. AWS EC2.
- **PaaS** — pre-configured dev environments. E.g. Heroku.
- **SaaS** — fully managed end-user apps. E.g. Google Workspace.
**Deployment models:** Public, Private, Hybrid, Multi-Cloud.
## Practical Impact / Security Relevance
Scalability & elasticity, cost efficiency (pay-as-you-go), and high availability via redundancy across geographically distributed data centers.
