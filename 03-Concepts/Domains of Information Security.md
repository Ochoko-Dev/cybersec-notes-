## 1. Network Security Firewalls, IDS (Intrusion Detection Systems), VPNs, encryption technologies.
## 2. Application Security Securing software and applications against vulnerabilities throughout their lifecycle.
## 3. Operational Security (OpSec) Key aspects: access control, asset management.
## 4. Cloud Security Shared responsibility model, data protection, Identity and Access Management (IAM).
## 5. Physical Security Protecting physical access to systems, hardware, and facilities.
## 6. Mobile Security Four layers: data security, device security, network security, application security.
## 7. Internet of Things (IoT) Security Securing connected devices (cameras, routers, sensors) — a growing attack surface, notably exploited in botnets like Mirai. See [[DDoS Attacks]].
