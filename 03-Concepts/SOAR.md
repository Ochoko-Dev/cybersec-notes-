# SOAR (Security Orchestration, Automation, and Response)

![[Pasted image 20260905101655.png]]

## Benefits
1. **Saves time** — automates workflows for common tasks such as IP address reputation checks, hash queries, and scanning an acquired file in a sandbox environment.
2. **Centralization** — allows use of different security tools in one environment (sandbox, log management, 3rd-party tools, etc.) through a single all-in-one platform.
