# Linux Distributions (Security Context)

## Debian
A stable, flexible Linux distribution commonly used for desktops, servers, embedded systems, and cybersecurity.

- **Package Management** — uses `apt` (Advanced Package Tool) for manual or automated software updates and security patches.
- **Control vs. Learning Curve** — configuration is complex for beginners, but mastering key tools/commands grants high system control and saves long-term configuration time.
- **Stability & Support** — provides Long-Term Support (LTS) releases with updates and security patches for up to five years, ideal for 24/7 server uptime.
- **Security & Privacy** — maintained by a community with a proven track record of rapidly patching vulnerabilities.
