# Introduction to the Shell

## Terminal Emulation
Terminal emulation is software that emulates the function of a terminal. Terminal emulators and multiplexers provide different methods to work with the terminal — splitting into multiple windows/panes, working across multiple directories, and creating separate workspaces.

## Shells
The most commonly used shell in Linux is the **Bourne-Again Shell (BASH)**.

Other shells: `Tcsh`/`Csh`, `Ksh`, `Zsh`, `Fish`.

## SSH (Secure Shell)
A protocol that allows clients to access and execute commands/actions on remote computers. Does not require a GUI.

Common SSH operations:
- Connect to a specific host
- Set up SSH key-based authentication
- Transfer files with SCP
