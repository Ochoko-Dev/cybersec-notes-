# SOC Overview

## SOC Models
- **In-house SOC** — a SOC team fully employed and operated internally by the organization.
- **Virtual SOC** — a distributed team with no dedicated physical facility, often working remotely.
- **Co-managed SOC** — internal team working jointly with an external/managed security provider.
- **Command SOC** — a top-level SOC that coordinates and oversees multiple subordinate SOCs (common in large/global organizations).

## SOC Roles
- SOC Analyst
- Incident Responder
- Threat Hunter
- Security Engineer
- SOC Manager

## Career Path Notes
Target role: **SOC Analyst**.
Core skills required: operating systems, networking, malware analysis.
