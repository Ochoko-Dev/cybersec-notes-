# Text Editors: Nano, Cat, Vim

- **nano** — allows you to create, open, and edit a file immediately.
- **cat** — view the contents of a file.
- **Vim** — an open-source editor, similar in purpose to nano.

## Benefits of Vim
- **Keyboard-driven speed** — navigate files, move entire blocks of code, and perform complex find-and-replace without leaving the home row or using a mouse.
- **Lightweight & ubiquitous** — runs natively inside command-line environments and remote SSH sessions with negligible memory usage.
- **Extensible & scriptable** — supports syntax highlighting, custom keybindings, and a plugin ecosystem (Vimscript or Lua).
