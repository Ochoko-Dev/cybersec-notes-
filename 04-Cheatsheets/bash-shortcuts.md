# Bash Shortcuts Cheatsheet

| Shortcut         | Action                                     |
| ---------------- | ------------------------------------------ |
| `TAB`            | Auto-complete based on current input       |
| `Ctrl + A`       | Move cursor to beginning of line           |
| `Ctrl + E`       | Move cursor to end of line                 |
| `Ctrl + ←` / `→` | Jump to beginning of current/previous word |
| `Alt + B` / `F`  | Jump backward/forward one word             |
| `Ctrl + U`       | Erase from cursor to beginning of line     |
| `Ctrl + K`       | Erase from cursor to end of line           |
| `Ctrl + W`       | Erase the word before the cursor           |
| `Ctrl + Y`       | Paste the erased text                      |
| `Ctrl + C`       | End current task/process (`SIGINT`)        |
| `Ctrl + D`       | Close STDIN pipe (EOF)                     |
| `Ctrl + L`       | Clear terminal (same as `clear`)           |
| `Ctrl + Z`       | Suspend current process (`SIGTSTP`)        |
| `Ctrl + R`       | Search command history                     |
| `↑` / `↓`        | Previous/next command in history           |
| `Alt + Tab`      | Switch between applications                |
| `Ctrl + +` / `-` | Zoom in/out                                |
