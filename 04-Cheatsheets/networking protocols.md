# Networking Protocols Cheatsheet

| Protocol                                          | Acronym  | Description                                                                                                |
| ------------------------------------------------- | -------- | ---------------------------------------------------------------------------------------------------------- |
| Wired Equivalent Privacy                          | `WEP`    | A type of security protocol that was commonly used to secure wireless networks.                            |
| Secure Shell                                      | `SSH`    | A secure network protocol used to log into and execute commands on a remote system.                        |
| File Transfer Protocol                            | `FTP`    | A network protocol used to transfer files from one system to another.                                      |
| Simple Mail Transfer Protocol                     | `SMTP`   | A protocol used to send and receive emails.                                                                |
| Hypertext Transfer Protocol                       | `HTTP`   | A client-server protocol used to send and receive data over the internet.                                  |
| Server Message Block                              | `SMB`    | A protocol used to share files, printers, and other resources in a network.                                |
| Network File System                               | `NFS`    | A protocol used to access files over a network.                                                            |
| Simple Network Management Protocol                | `SNMP`   | A protocol used to manage network devices.                                                                 |
| Wi-Fi Protected Access                            | `WPA`    | A wireless security protocol that uses a password to protect wireless networks from unauthorized access.   |
| Temporal Key Integrity Protocol                   | `TKIP`   | A security protocol used in wireless networks, less secure than WPA2/3.                                    |
| Network Time Protocol                             | `NTP`    | Used to synchronize the timing of computers on a network.                                                  |
| Virtual Local Area Network                        | `VLAN`   | A way to segment a network into multiple logical networks.                                                 |
| VLAN Trunking Protocol                            | `VTP`    | A Layer 2 protocol used to establish and maintain a VLAN spanning multiple switches.                       |
| Routing Information Protocol                      | `RIP`    | A distance-vector routing protocol used in LANs and WANs.                                                  |
| Open Shortest Path First                          | `OSPF`   | An interior gateway protocol (IGP) for routing traffic within a single Autonomous System (AS).             |
| Interior Gateway Routing Protocol                 | `IGRP`   | Cisco-proprietary interior gateway protocol for routing within autonomous systems.                         |
| Enhanced Interior Gateway Routing Protocol        | `EIGRP`  | An advanced distance-vector routing protocol used to route IP traffic within a network.                    |
| Pretty Good Privacy                               | `PGP`    | An encryption program used to secure emails, files, and other data.                                        |
| Network News Transfer Protocol                    | `NNTP`   | A protocol used for distributing and retrieving messages in newsgroups across the internet.                |
| Cisco Discovery Protocol                          | `CDP`    | Cisco-proprietary protocol that lets admins discover and manage connected Cisco devices.                   |
| Hot Standby Router Protocol                       | `HSRP`   | A Cisco protocol providing router redundancy in the event of a device failure.                             |
| Virtual Router Redundancy Protocol                | `VRRP`   | Provides automatic assignment of available IP routers to participating hosts.                              |
| Spanning Tree Protocol                            | `STP`    | Ensures a loop-free topology in Layer 2 Ethernet networks.                                                 |
| Terminal Access Controller Access-Control System  | `TACACS` | Provides centralized authentication, authorization, and accounting for network access.                     |
| Session Initiation Protocol                       | `SIP`    | A signaling protocol for establishing/terminating real-time voice, video, and multimedia sessions over IP. |
| Voice Over IP                                     | `VOIP`   | Technology that allows telephone calls to be made over the internet.                                       |
| Extensible Authentication Protocol                | `EAP`    | A framework for authentication supporting multiple methods (passwords, certs, OTPs, public-key).           |
| Lightweight Extensible Authentication Protocol    | `LEAP`   | Cisco-proprietary wireless authentication protocol based on EAP, used in PPP.                              |
| Protected Extensible Authentication Protocol      | `PEAP`   | A security protocol that provides an encrypted tunnel for wireless and other network types.                |
| Systems Management Server                         | `SMS`    | A systems management solution for organizing networks, systems, and mobile devices.                        |
| Microsoft Baseline Security Analyzer              | `MBSA`   | A free Microsoft tool for detecting security vulnerabilities in Windows computers/networks.                |
| Supervisory Control and Data Acquisition          | `SCADA`  | An industrial control system used to monitor/control processes like manufacturing or power generation.     |
| Virtual Private Network                           | `VPN`    | Allows users to create a secure, encrypted connection to another network over the internet.                |
| Internet Protocol Security                        | `IPsec`  | Provides secure, encrypted communication over a network — commonly used to build VPN tunnels.              |
| Point-to-Point Tunneling Protocol                 | `PPTP`   | Used to create a secure, encrypted tunnel for remote access.                                               |
| Network Address Translation                       | `NAT`    | Lets multiple devices on a private network share a single public IP for internet access.                   |
| Carriage Return Line Feed                         | `CRLF`   | Two control characters marking the end of a line and start of a new one in certain text formats.           |
| Asynchronous JavaScript and XML                   | `AJAX`   | A web dev technique for creating dynamic pages using JavaScript and XML/JSON.                              |
| Internet Server Application Programming Interface | `ISAPI`  | Used to create performance-oriented web extensions for web servers via a set of APIs.                      |
| Uniform Resource Identifier                       | `URI`    | Syntax used to identify a resource on the internet.                                                        |
| Uniform Resource Locator                          | `URL`    | Subset of URI that identifies a web page or resource, including protocol and domain name.                  |
| Internet Key Exchange                             | `IKE`    | Sets up a secure connection between two computers — used in VPNs for authentication/encryption.            |
| Generic Routing Encapsulation                     | `GRE`    | Used to encapsulate data being transmitted within a VPN tunnel.                                            |
| Remote Shell                                      | `RSH`    | A Unix program that allows executing commands/programs on a remote computer.                               |
